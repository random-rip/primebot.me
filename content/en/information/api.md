---
title: Unofficial Prime League API
---

::note
Only data of registered teams (that use PrimeBot) is available.
::

Many organizations would like to present their teams and players on their own website. So far, the Prime League does not offer an official API to retrieve team and player data. That's why we built an unofficial API.

All endpoints are documented in the [Open API Swagger documentation](https://primebot.me/api/v1/){target="_blank"}.

Among other things, the API provides the following information:

- Teams: information about teams, e.g. team name, team members and matches
- Players: information about players, e.g. player name
- Matches: information about matches, e.g. date, opponent and result

## Rate limits

The API is limited to 1000 requests per day per user. If that isn't enough, please contact us.

## Contributing

The API is open source and we welcome contributions. If you find a bug or want to suggest an improvement, please open an issue or a pull request on [GitHub](https://github.com/random-rip/primebot_backend).

## FAQ

> Why isn't the division included in the API?

About a year ago, the Prime League removed the division from the data provided to us. The division is now only visible on the Prime League website.
